# Save State

Save State is a React library for tracking save lifecycles across local and remote persistence.

## Workspace layout

- `packages/savestate` – reusable library
- `apps/docs` – documentation and interactive showcase

## Quick start

```bash
pnpm install
pnpm build
```

## Features

- `useSaveState` hook
- `SaveIndicator`, `SaveButton`, and `SaveStatus`
- Local persistence adapters
- Offline + conflict state modeling
- AI-friendly metadata and agent API
